# Aportaciones

Si tu cuenta es una cuenta distribuidora activa y no tiene la funcionalidad **Compensación**, esta opción aparece en el menú **Propiedades**. Muestra las aportaciones de compensación que han hecho los huéspedes desde las calculadoras de las propiedades.

> **Dónde está:** menú **Propiedades › Aportaciones**. La pantalla se titula **Aportaciones a proyectos**.

## Qué ves en la pantalla

| Columna | Qué significa |
|---|---|
| **Proyecto** | Proyecto al que se destina. |
| **Cuenta** | Cuenta de la propiedad. |
| **Propiedad** | Propiedad desde la que se hizo. |
| **Aportante** | Quién la hizo. |
| **Toneladas** | Toneladas de CO₂ compensadas. |
| **Total** | Importe. |
| **Estado** | **Pendiente**, **Pagado**, **Fallido** o **Caducado**. |
| **Fecha** | |

Pulsa **Filtrar** para elegir **Proyecto**, **Propiedad**, **Estado** o fechas (**Desde** / **Hasta**).

## Ver una aportación

Pulsa **Detalles** para ver el detalle de la aportación: proyecto, toneladas, emisiones compensadas, desglose económico (**Aportación al proyecto**, **Margen de gestión**, **Base imponible**, **IVA**, **Total**), datos del aportante y del pago.

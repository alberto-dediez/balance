# Eventos

Aquí registras los eventos que organizas para calcular y compensar su huella de carbono. Esta opción aparece si tu cuenta tiene activada la funcionalidad **Eventos**.

> **Dónde está:** menú **Eventos › Eventos**.

## Qué ves en la pantalla

| Columna | Qué significa |
|---|---|
| **Nombre** | Nombre del evento. |
| **Ubicación** | Dónde se celebra. |
| **Tamaño del evento** | **Local**, **Regional**, **Nacional** o **Internacional**. |
| **Sector del evento** | |
| **Fecha de registro** | |

Pulsa **Filtrar** para buscar por **Nombre**, **Ubicación**, **Instalación**, **Empresa**, **Tamaño del evento**, **Sector del evento** o **Tipología del evento**.

## Registrar un evento

1. Pulsa **Registrar**.
2. Rellena el formulario, organizado en **General** y **Planificación**:

   | Campo | Obligatorio | Qué poner |
   |---|---|---|
   | **Nombre** | Sí | |
   | **Ubicación** | Sí | Ciudad o lugar. |
   | **Instalación** | No | Una de tus propiedades, o **Sin instalación**. |
   | **Empresa** | No | Una de tus empresas, o **Sin empresa**. |
   | **Tamaño del evento** | Sí | |
   | **Nº de asistentes (estimado)** | No | |
   | **Sector del evento** | Sí | |
   | **Tipología del evento** | Sí | **Micro (5 a 50 participantes)**, **Pequeño (51 a 250 participantes)**, **Mediano**, **Grande** o **Macro**. |
   | **Sede del evento** | No | Punto exacto de celebración. Se usa para calcular las distancias de los asistentes en la huella de carbono. |
   | **Inicio del montaje** / **Fin del montaje** | Sí | |
   | **Inicio de la celebración** / **Fin de la celebración** | Sí | |
   | **Inicio del desmontaje** / **Fin del desmontaje** | Sí | |

3. Pulsa **Registrar**. Verás **Evento creado correctamente** con su nombre.

## Editar o eliminar un evento

- **Editar**: cambia los datos y pulsa **Guardar** o **Guardar y salir**. Verás **Evento actualizado con éxito**. Si su huella de carbono ya está completada verás **La huella de carbono de este evento está completada: los datos solo se pueden consultar.**
- **Eliminar**: confirma el aviso. Verás **Se ha eliminado el evento** con su nombre.

## Encuesta de asistentes

Cada evento tiene una encuesta pública con la que los asistentes indican cómo han viajado y dónde han dormido (y pueden compensar sus emisiones).

- Pulsa **Calculadora** en la fila. Verás el QR y el **Enlace de la encuesta de asistentes**, con el botón **Copiar**, para compartirlos.
- Pulsa **Respuestas** para ver sus estadísticas: **Respuestas recibidas**, **% encuestados**, **Emisiones declaradas**, medias, **Emisiones compensadas**, **Importe aportado**, **Participación voluntaria**, gráficos por día, concepto y medio de transporte, **Perfil de los asistentes**, **Principales orígenes** y el **Detalle de la encuesta** (abierta o cerrada). Desde ahí puedes **Exportar** las respuestas.

## Calcular la huella de carbono

Pulsa **Cálculo de Huella de Carbono** en la fila. La primera vez se crea la huella del evento y entras en su asistente. Se explica en [Huella de carbono de un evento](eventos-huella-de-carbono.md).

Cuando el informe esté emitido, la fila muestra también **Descargar**.

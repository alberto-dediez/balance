# Aportaciones

Cada aportación es un pago o una compensación concreta a un proyecto: las tuyas, y las de los asistentes, huéspedes, empleados o proveedores que compensan desde tus encuestas y calculadoras. Esta opción aparece si tu cuenta tiene activada la funcionalidad **Compensación**.

> **Dónde está:** menú **Proyectos › Aportaciones**. La pantalla se titula **Aportaciones a proyectos**.

## Qué ves en la pantalla

| Columna | Qué significa |
|---|---|
| **Proyecto** | Proyecto al que se destina. |
| **Cuenta** | Cuenta a la que pertenece. |
| **Propiedad** | Propiedad desde la que se hizo, si la hay. |
| **Aportante** | Quién la hizo. |
| **Toneladas** | Toneladas de CO₂ compensadas. |
| **Total** | Importe. |
| **Estado** | **Pendiente**, **Pagado**, **Fallido** o **Caducado**. |
| **Fecha** | |

Pulsa **Filtrar** para elegir **Proyecto**, **Propiedad**, **Estado** o fechas (**Desde** / **Hasta**).

## Ver una aportación

Pulsa **Detalles**. Verás:

- **Aportación**: **Proyecto**, **Estado**, **Toneladas**, **Emisiones compensadas**, si fue una **Aportación libre**, el precio por tonelada y las fechas.
- **Desglose económico**: **Aportación al proyecto**, **Margen de gestión**, **Base imponible**, **IVA** y **Total**.
- **Datos fiscales del aportante**: **Nombre**, **Email**, **País** y, si es empresa, **Razón social** y **NIF / NIF-IVA**.
- **Pago**: **Estado**, **Pasarela** y **Referencia del pago**, o **Esta aportación no tiene ningún pago asociado** si se compensó con créditos.

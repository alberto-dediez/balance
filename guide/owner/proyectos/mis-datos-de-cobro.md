# Mis datos de cobro

Para que la plataforma pueda abonarte tu saldo necesita tus datos fiscales y tu cuenta bancaria. Esta opción aparece si tu cuenta tiene activada la funcionalidad **Compensación**.

> **Dónde está:** menú **Proyectos › Mis datos de cobro**, o el botón **Completar datos de cobro** de **Mi saldo**.

## Rellenar tus datos

1. Abre **Mis datos de cobro**.
2. Rellena el formulario:

   | Campo | Obligatorio | Qué poner |
   |---|---|---|
   | **Razón social** | Sí | Nombre fiscal. |
   | **NIF / CIF** | Para cobrar | |
   | **Dirección**, **Código postal**, **Ciudad**, **País** | No | |
   | **IBAN** | Para cobrar | Cuenta donde recibir los pagos. |
   | **BIC** | No | |
   | **Titular de la cuenta** | Para cobrar | |
   | **Notas** | No | |

3. Pulsa **Guardar datos de cobro**. Verás **Datos de cobro guardados con éxito**.

## Conviene saber

- Completa la razón social, el NIF, el IBAN y el titular de la cuenta: sin ellos no se te puede pagar.
- Si tus datos están bloqueados verás **Sus datos de cobro están bloqueados. Póngase en contacto con nosotros para poder modificarlos.**

# Proveedores

Tus proveedores son las empresas externas que prestan servicios en tus eventos o a tus propiedades y empresas. Al calcular una huella puedes pedirles por correo sus propios datos de emisiones, o introducirlos tú. Esta opción aparece si tu cuenta tiene activada la funcionalidad **Eventos** o **Huella de carbono de propiedades y empresas**.

> **Dónde está:** menú **Proveedores › Proveedores**.

## Qué ves en la pantalla

| Columna | Qué significa |
|---|---|
| **Nombre** | Nombre del proveedor. |
| **CIF** | Identificación fiscal. |
| **Ciudad** | |
| **Fecha de registro** | |

Pulsa **Filtrar** para buscar por **Nombre**.

## Registrar un proveedor

1. Pulsa **Registrar**.
2. Rellena el formulario, organizado en **General** y **Contacto para recogidas**:

   | Campo | Obligatorio | Qué poner |
   |---|---|---|
   | **Nombre** | Sí | |
   | **CIF** | Sí | |
   | **Calle**, **Código postal**, **Ciudad**, **País** | No | |
   | **Email de contacto** | Sí | A este correo le llegarán las solicitudes de datos. |
   | **Nombre de contacto** | No | |
   | **Idioma preferido** | No | Idioma de los correos que recibe. |

3. Pulsa **Registrar**. Verás **Proveedor creado correctamente** con su nombre.

## Editar o eliminar un proveedor

- **Editar**: cambia los datos y pulsa **Guardar** o **Guardar y salir**. Verás **Proveedor actualizado con éxito**.
- **Eliminar**: confirma el aviso. Verás **Se ha eliminado el proveedor** con su nombre.

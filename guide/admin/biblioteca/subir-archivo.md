# Subir archivo

Sube a la biblioteca imágenes, documentos u otros ficheros para tenerlos a mano y usarlos en otras pantallas (por ejemplo, como imagen de perfil).

> **Dónde está:** menú **Biblioteca › Subir archivo**, o el botón **Subir archivo** del listado de archivos.

## Subir archivos

1. Abre **Subir archivo**.
2. Rellena el formulario:

   | Campo | Obligatorio | Qué poner |
   |---|---|---|
   | **Archivo** | Sí | Uno o varios ficheros de tu equipo. |
   | **Nombre** | No | Si lo dejas vacío se usa el nombre del fichero. Solo se aplica si subes un único archivo. |
   | **Texto alternativo** | No | Descripción breve de la imagen. Solo se aplica si subes un único archivo. |
   | **Descripción** | No | Notas sobre el archivo. Solo se aplica si subes un único archivo. |
   | **Visibilidad** | Sí | Quién puede abrir los archivos: **Solo mi cuenta**, **Usuarios de la plataforma** o **Público**. |
   | **Compartir en la biblioteca** | No | Los archivos aparecerán en la biblioteca del resto de cuentas, que podrán usarlos. |

3. Pulsa **Subir**.

Volverás al listado con el mensaje **Archivo subido correctamente** (o **Archivos subidos correctamente** si eran varios) y los nombres de lo que has subido.

## Conviene saber

- Si subes varios archivos a la vez, todos reciben la misma visibilidad y cada uno conserva el nombre de su fichero.
- Si no estás dentro de ninguna cuenta, los archivos se guardan en la biblioteca de la plataforma. Si has entrado en una cuenta con **Cambiar de cuenta**, se guardan en la de esa cuenta.

# Proyectos

Los proyectos son las iniciativas a las que se destinan las aportaciones de compensación: proyectos de compensación de emisiones o proyectos sociales. Las cuentas se adhieren a los proyectos que quieren usar.

> **Dónde está:** menú **Proyectos › Proyectos**.

## Qué ves en la pantalla

| Columna | Qué significa |
|---|---|
| **Nombre** | Nombre del proyecto. |
| **Localización** | Dónde se desarrolla. |
| **Tipo de proyecto** | **Compensación de emisiones** o **Proyecto social**. |
| **Estado del proyecto** | **Pendiente**, **En progreso** o **Ejecutado**. |
| **Fecha de registro** / **Fecha de actualización** | |

Pulsa **Filtrar** para buscar por **Nombre**, **Tipo de proyecto**, **Estado del proyecto**, **Código Registro Miteco** o **Adherido**.

## Registrar un proyecto

1. Pulsa **Registrar**.
2. Rellena el formulario, organizado en **General**, **Descripción** y **Galería**:

   | Campo | Obligatorio | Qué poner |
   |---|---|---|
   | **Nombre** | Sí | |
   | **Descripción** | Sí | Texto que verán las cuentas y quienes aporten. |
   | **Localización** | Sí | |
   | **Galería** | No | Imágenes de la biblioteca. |
   | **Tipo de proyecto** | Sí | |
   | **Estado del proyecto** | Sí | |
   | **Código Registro Miteco** | No | Código del proyecto en el registro oficial. |
   | **Coste por tonelada (€)** | Sí | Lo que cuesta a la plataforma cada tonelada. |
   | **Precio por tonelada (€)** | No | Lo que paga quien compensa por tonelada. |

3. Pulsa **Registrar**. Verás **Proyecto creado correctamente** con su nombre.

## Editar un proyecto

Pulsa **Editar**, cambia los datos y pulsa **Guardar** o **Guardar y salir**. Verás **Proyecto actualizado con éxito**. En la ficha también ves las **Cuentas adheridas** al proyecto (o **Ninguna cuenta ha adherido este proyecto**). Los textos se guardan en el idioma en que tienes la plataforma.

## Eliminar un proyecto

Pulsa **Eliminar** y confirma. Verás **Se ha eliminado el proyecto** con su nombre.

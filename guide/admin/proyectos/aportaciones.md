# Aportaciones

Cada aportación es un pago concreto de compensación a un proyecto, hecho por un propietario, un asistente, un huésped, un empleado o un proveedor. Aquí ves las de todas las cuentas.

> **Dónde está:** menú **Proyectos › Aportaciones**. La pantalla se titula **Aportaciones a proyectos**.

## Qué ves en la pantalla

| Columna | Qué significa |
|---|---|
| **Cuenta** | Cuenta a la que pertenece. |
| **Proyecto** | Proyecto al que se destina. |
| **Aportante** | Quién ha pagado. |
| **Toneladas** | Toneladas de CO₂ compensadas. |
| **Total** | Importe pagado. |
| **Estado** | **Pendiente**, **Pagado**, **Fallido** o **Caducado**. |
| **Fecha** | |

Pulsa **Filtrar** para elegir una **Cuenta**.

## Ver una aportación

Pulsa **Detalles**. Verás:

- El **Certificado**: **Código**, **Tipo**, **Estado**, **Fecha de emisión** y, si falló, el **Motivo del fallo**. Pulsa **Descargar** para obtenerlo, o escribe un **Correo electrónico** y pulsa **Reenviar** para mandarlo. Verás **Certificado enviado.** Si aún no existe verás **Esta aportación todavía no tiene certificado**.
- Los **Lotes de crédito consumidos**: de qué compra de crédito salen las toneladas compensadas (**Compra de crédito**, **Referencia**, **Toneladas**).

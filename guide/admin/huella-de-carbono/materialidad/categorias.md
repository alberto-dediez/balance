# Categorías

El análisis de materialidad ayuda a las cuentas a decidir qué categorías del alcance 3 deben calcular en la huella de una propiedad o una empresa. Cada categoría (por ejemplo, **Viajes de negocios**) se evalúa con un cuestionario. Aquí mantienes la lista de categorías.

> **Dónde está:** menú **Huella de carbono › Materialidad › Categorías**.

## Qué ves en la pantalla

| Columna | Qué significa |
|---|---|
| **Nº** | Número de la categoría. |
| **Nombre** | Nombre de la categoría. |
| **Alcance** | **Alcance 1**, **Alcance 2** o **Alcance 3**. |
| **Dirección** | **Aguas arriba** o **Aguas abajo**. |
| **Estándar** | Si es una de las categorías estándar del GHG Protocol. |
| **Activa** | **Activa** o **Inactiva**. |
| **Posición** | Orden en el que aparece. |
| **Fecha de registro** / **Fecha de actualización** | Cuándo se creó y se modificó por última vez. |

Pulsa **Filtrar** para buscar por **Nombre**, **Alcance**, **Dirección** o **Activa**.

## Cargar las categorías estándar

Pulsa **Sembrar maestros estándar** y confirma. Se registrarán las categorías estándar del GHG Protocol que falten y, si no hay preguntas, las preguntas iniciales. Si ya estaban todas verás **Los maestros estándar ya estaban registrados**.

## Registrar una categoría

1. Pulsa **Registrar**.
2. Rellena el formulario:

   | Campo | Obligatorio | Qué poner |
   |---|---|---|
   | **Nº de categoría** | No | Número de la categoría. |
   | **Alcance** | Sí | Alcance al que pertenece. |
   | **Dirección** | No | **Aguas arriba**, **Aguas abajo** o **Sin dirección**. |
   | **Nombre** | Sí | |
   | **Descripción** | No | |
   | **Posición** | Sí | Orden en la lista. |

3. Pulsa **Registrar**. Verás **Categoría de materialidad creada correctamente** con su nombre.

## Editar una categoría

Pulsa **Editar**. Verás su **Nº de categoría** y si es **Estándar**, y podrás cambiar el resto de campos y marcar o desmarcar **Activa**. Pulsa **Guardar** o **Guardar y salir**. Verás **Categoría de materialidad actualizada con éxito**. Los textos se guardan en el idioma en que tienes la plataforma.

## Eliminar una categoría

Pulsa **Eliminar** y confirma. Verás **Se ha eliminado la categoría de materialidad** con su nombre.

## Conviene saber

- Las categorías estándar no se pueden eliminar; si no quieres usar una, desmárcala como **Activa**.
- Cambiar la configuración o las categorías no altera las evaluaciones que las cuentas ya han completado.

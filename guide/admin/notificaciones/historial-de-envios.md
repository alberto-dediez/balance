# Historial de envíos

Lista todas las notificaciones que ha enviado la plataforma, una fila por destinatario y canal. Esta opción aparece si tu plataforma lo tiene activado.

> **Dónde está:** menú **Notificaciones › Historial de envíos**.

## Qué ves en la pantalla

| Columna | Qué significa |
|---|---|
| **Fecha** | Cuándo se generó. |
| **Destinatario** | Usuario que la recibe. |
| **Cuenta** | Cuenta del destinatario. |
| **Canal** | **Interna**, **Email**, **SMS** o **WhatsApp**. |
| **Asunto** | Título del aviso. |
| **Estado** | **Pendiente**, **Enviada** o **Fallida**. |

Pulsa **Filtrar** para elegir un **Canal** (**Todos los canales**) o un **Estado** (**Todos los estados**).

## Enviar una nueva

Pulsa **Enviar notificación** para ir al formulario de envío.

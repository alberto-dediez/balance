# Libro mayor

Cada aportación cobrada genera varios asientos: el neto que corresponde a la cuenta o al proyecto, los gastos de gestión y el IVA. El libro mayor los lista todos, junto con los ajustes manuales.

> **Dónde está:** menú **Tesorería › Libro mayor**.

## Qué ves en la pantalla

| Columna | Qué significa |
|---|---|
| **Fecha** | Fecha del asiento. |
| **Tipo** | **Neto de la aportación**, **Gastos de gestión**, **IVA** o **Ajuste**. |
| **Destino** | **Bioscore**, **Cuenta**, **Proyecto** o **Sin asignar**. |
| **Aportación** | Aportación que lo origina (enlace a su detalle). |
| **Lote** | Lote de crédito relacionado (**Ver lote**). |
| **Toneladas** | Toneladas compensadas. |
| **Importe** | |
| **Liquidación** | Liquidación en la que se ha pagado (**Ver**) o **Pendiente**. |

Pulsa **Filtrar** para elegir **Tipo**, **Destino** o fechas (**Desde** / **Hasta**).

## Registrar un ajuste

1. Pulsa **Registrar ajuste**.
2. Elige el **Beneficiario**, escribe el **Importe** y el **Motivo**.
3. Pulsa **Registrar ajuste**. Verás **Ajuste registrado correctamente**.

## Revertir un asiento

En los asientos que lo permiten aparece **Revertir**. Se abre **Revertir asiento** con el **Asiento que se revierte** (**Fecha**, **Tipo**, **Destino**, **Importe original**) y el formulario de ajuste ya preparado para compensarlo. Pulsa **Registrar ajuste**.

# Beneficiarios

Un beneficiario es una cuenta o un proyecto a quien la plataforma paga lo que le corresponde. Para poder pagarle necesita una ficha con sus datos fiscales y bancarios; las cuentas pueden rellenarla ellas mismas en **Mis datos de cobro**, o puedes hacerlo tú aquí.

> **Dónde está:** menú **Tesorería › Beneficiarios**.

## Qué ves en la pantalla

| Columna | Qué significa |
|---|---|
| **Razón social** | Nombre fiscal. |
| **Tipo** | **Cuenta** o **Proyecto**. |
| **Cuenta o proyecto** | A quién corresponde. |
| **NIF / CIF** | |
| **IBAN** | Cuenta bancaria. |
| **Estado** | **Incompleto**, **Listo** o **Bloqueado**. |
| **Pendiente de liquidar** | Saldo que se le debe. |

Pulsa **Filtrar** para elegir **Tipo**, **Estado** o **Buscar** por texto.

## Registrar un beneficiario

1. Pulsa **Registrar**.
2. Elige el **Tipo de beneficiario** y la **Cuenta o proyecto**.
3. Rellena los **Datos fiscales** (**Razón social** obligatoria, **NIF / CIF**, **Dirección**, **Código postal**, **Ciudad**, **País**), los **Datos bancarios** (**IBAN**, **BIC**, **Titular de la cuenta**) y las **Notas**.
4. Pulsa **Crear beneficiario**.

## Editar un beneficiario

Pulsa **Editar**, cambia los datos y pulsa **Guardar beneficiario**. Verás **Beneficiario actualizado con éxito**.

## Bloquear o desbloquear

Pulsa **Bloquear** para impedir que se le paguen liquidaciones, o **Desbloquear** para volver a permitirlo. Verás **Beneficiario bloqueado** o **Beneficiario desbloqueado**.

## Crear una liquidación

Si tiene saldo pendiente, pulsa **Crear liquidación** y confirma.

# Changelog

Es el registro de los cambios que se han ido entregando en la plataforma, pensado para los administradores. A diferencia de **Novedades**, no se redacta desde aquí: solo se consulta.

> **Dónde está:** menú **Novedades › Changelog**.

## Qué ves en la pantalla

| Columna | Qué significa |
|---|---|
| **Fecha** | Fecha de la entrega. |
| **Categoría** | **Nueva funcionalidad**, **Mejora**, **Corrección** o **Seguridad**. |
| **Título** | Nombre del cambio. |
| **Resumen** | Explicación breve. |

Pulsa **Filtrar** para **Buscar** por texto o elegir una **Categoría**. Si no hay ninguna entrada verás **No hay novedades publicadas**.

## Ver una entrada

Pulsa **Detalles** en la fila. Verás el contenido completo y, si existen:

- **Ver manual** (se abre en otra pestaña) y **Descargar manual**: el manual de usuario de ese cambio.
- **Manual técnico**: solo para superadministradores, el documento técnico del cambio.

Pulsa **Volver** para regresar al listado.

# Registro

La plataforma anota cada cambio que se hace: altas, modificaciones, borrados, envíos, firmas… Aquí puedes consultarlo todo, con el usuario que lo hizo y, si estaba dentro de la sesión de otro, quién era en realidad.

> **Dónde está:** menú **Administración › Auditoría › Registro**. La pantalla se titula **Eventos**.

## Qué ves en la pantalla

| Columna | Qué significa |
|---|---|
| **Detalle** | Resumen legible de lo que cambió. |
| **Usuario** | Quién lo hizo. |
| **Suplantado por** | Si el cambio se hizo desde la sesión de otro usuario, el administrador que estaba detrás. |
| **Nombre** | Tipo de cambio. |
| **Contexto** | Área de la plataforma a la que pertenece. |
| **Fecha de registro** | Cuándo ocurrió. |

## Filtrar

Pulsa **Filtrar** para buscar por **Nombre**, **Contexto**, **Usuario**, **Suplantado por** o **Entidad** (un elemento concreto).

## Conviene saber

- Muchas pantallas tienen un botón **Histórico** que abre este mismo registro filtrado por el elemento de esa fila.

# Destinos

Los destinos son las zonas turísticas donde están las propiedades; cada uno pertenece a un país. Esta opción aparece si tu plataforma lo tiene activado.

> **Dónde está:** menú **Propiedades › Destinos**.

## Qué ves en la pantalla

| Columna | Qué significa |
|---|---|
| **Nombre** | Nombre del destino. |
| **País** | País al que pertenece. |
| **Fecha de registro** | Cuándo se dio de alta. |

Pulsa **Filtrar** para buscar por **Nombre** o **País** (**Todos los países**).

## Registrar

1. Pulsa **Registrar**.
2. Rellena el formulario:

   | Campo | Obligatorio | Qué poner |
   |---|---|---|
   | **Nombre** | Sí | |
   | **País** | Sí | |
   | **Identificadores externos** | No | Códigos de este elemento en otros sistemas (**Hotelbeds ID**, **Restel ID**, **Bioscore ID**). |

3. Pulsa **Registrar**. Verás **Destino creado correctamente:** seguido del nombre.

## Editar

Pulsa **Editar**, cambia los datos y pulsa **Guardar** o **Guardar y salir**. Verás **Destino actualizado con éxito**.

## Eliminar

Pulsa **Eliminar** y confirma. Verás **Se ha eliminado el destino** seguido del nombre.

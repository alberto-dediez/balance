# Países

Los países agrupan los destinos y guardan datos fiscales básicos. Esta opción aparece si tu plataforma lo tiene activado.

> **Dónde está:** menú **Propiedades › Países**.

## Qué ves en la pantalla

| Columna | Qué significa |
|---|---|
| **Nombre** | Nombre del país. |
| **ISO** | Código ISO. |
| **UE** | Si pertenece a la Unión Europea. |
| **IVA %** | Tipo de IVA. |
| **Fecha de registro** | Cuándo se dio de alta. |

## Registrar

1. Pulsa **Registrar**.
2. Rellena el formulario:

   | Campo | Obligatorio | Qué poner |
   |---|---|---|
   | **Nombre** | Sí | |
   | **ISO** | No | Código ISO del país. |
   | **Unión Europea** | No | Márcalo si es miembro. |
   | **Tipo de IVA (%)** | No | |
   | **Identificadores externos** | No | Códigos de este elemento en otros sistemas (**Hotelbeds ID**, **Restel ID**, **Bioscore ID**). |

3. Pulsa **Registrar**. Verás **País creado correctamente:** seguido del nombre.

## Editar

Pulsa **Editar**, cambia los datos y pulsa **Guardar** o **Guardar y salir**. Verás **País actualizado con éxito**.

## Eliminar

Pulsa **Eliminar** y confirma. Verás **Se ha eliminado el país** seguido del nombre.
